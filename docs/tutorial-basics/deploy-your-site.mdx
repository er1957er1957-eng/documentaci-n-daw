# Gestión de incidencias

## Ciclo de vida
Una incidencia atraviesa varios estados desde su creación hasta su cierre definitivo:

- Abierta
- En revisión
- Asignada
- En proceso
- Resuelta
- Cerrada

## Flujo recomendado
1. El usuario registra la incidencia con descripción y prioridad.
2. El sistema valida el formato y la categoría asociada.
3. Un operador revisa la información y la deriva al técnico correcto.
4. El técnico documenta la solución y marca la incidencia como resuelta.
5. El cliente confirma o cierra la tarea si todo está correcto.

## Priorización
La prioridad se calcula a partir de:
- impacto sobre el servicio
- urgencia del usuario
- criticidad del área afectada
- SLA asociado

## Notificaciones
El sistema notifica al responsable de cada cambio mediante correo interno o mensaje de la plataforma para evitar retrasos en la resolución.

## Indicadores clave
- Tiempo medio de resolución
- Incidencias abiertas por equipo
- Tasa de cierre en SLA
- Reincidencias por categoría
