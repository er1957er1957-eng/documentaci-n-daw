# Introducción del proyecto

## Visión general
La aplicación desarrollada consiste en una plataforma de gestión de incidencias y soporte técnico para equipos internos de una organización. El sistema permite registrar, priorizar, asignar y resolver incidencias de forma centralizada, con trazabilidad completa y acceso multicanal desde web y móvil.

## Objetivos
- Centralizar el flujo de trabajo de soporte técnico.
- Reducir el tiempo de resolución mediante automatización de tareas repetitivas.
- Garantizar la seguridad y trazabilidad de cada incidencia.
- Facilitar la toma de decisiones con paneles de control y reportes ejecutivos.

## Usuarios del sistema
- Administradores: gestionan usuarios, permisos, configuraciones y métricas.
- Técnicos: revisan incidencias, actualizan estados y registran soluciones.
- Operadores: reciben y derivan solicitudes desde distintos canales.
- Clientes internos: reportan incidencias y consultan su estado.

## Stack principal
- Frontend: React + TypeScript
- Backend: Node.js + Express
- Base de datos: PostgreSQL
- Autenticación: JWT + OAuth2
- Despliegue: Docker + GitHub Actions

## Alcance funcional
El sistema cubre la captura, clasificación, asignación, resolución y cierre de incidencias; además incorpora notificaciones, auditoría y exportación de reportes para diferentes niveles de gestión.
